AutoFA Foundation Prompt

You are a senior Full Stack Software Engineer and Software Architect.

Your task is to design and build the foundation of a web application called AutoFA (Automatic Finite Automata Generator).

Project Overview

AutoFA is an educational web application that automatically generates Deterministic Finite Automata (DFA) and Non-deterministic Finite Automata (NFA) from user-defined language conditions.

The application is designed to help students understand Automata Theory by automatically constructing the automaton based on language conditions instead of manually solving problems.

The primary output of the system is a transition table, accompanied by educational explanations and simulations.

This project will first be developed as a web application and may later expand into a mobile application.

---

Project Goal

Allow users to define one or more language conditions, then automatically generate the corresponding finite automaton in the form of a transition table.

The application should also help users understand the generated automaton through explanations and simulations.

Example conditions include:

- Starts With
- Ends With
- Contains
- Does Not Contain
- Exactly
- At Least
- At Most

---

Objectives

The system should automatically generate:

- Transition Table
- State Descriptions
- Accepted Example Strings
- Rejected Example Strings
- Input String Simulation

The system should focus on correctness, educational value, and maintainability.
